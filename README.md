# Employee Attrition Prediction Using Machine Learning

## Project Overview

This project develops a machine learning classification system to predict employee attrition based on employee demographic, job-related, and satisfaction-related features.

The project includes data preprocessing, machine learning pipeline development, model optimization, evaluation, and deployment using Gradio.

---

## Dataset

Dataset:
IBM HR Analytics Employee Attrition Dataset

Task:
Binary Classification

Target:
Attrition

Classes:
- Yes: Employee leaves the organization
- No: Employee stays in the organization

---

## Machine Learning Workflow

The project follows these steps:

1. Data Loading
2. Data Preprocessing
3. Feature Engineering
4. Machine Learning Pipeline Creation
5. Model Training
6. Cross Validation
7. Hyperparameter Optimization
8. Model Evaluation
9. Gradio Web Application
10. Deployment Preparation

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Gradio

---

## Model

Primary Model:
Random Forest Classifier

Reason:
Random Forest was selected because it performs well on tabular datasets and can capture nonlinear relationships between employee features and attrition outcomes.

---

## Deployment

The trained model is deployed using a Gradio interface.
